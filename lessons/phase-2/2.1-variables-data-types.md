# وانەی 2.1 — Variables، Data Types و Operators لە PHP

## ئامانجەکانی فێربوون
دوای ئەم وانەیە دەتوانیت:
- Variable دروست بکەیت لە PHP و بزانیت بۆچی بە نیشانەی دۆلار ($) دەستپێدەکات.
- جیاوازی نێوان جۆرە سەرەکییەکانی داتا (string, int, float, boolean) بناسیتەوە.
- Operator ـە بنەڕەتییەکان (Arithmetic, Comparison, Logical, Assignment) بە دروستی بەکاربهێنیت.

## پێشمەرج
دەبێت پێشتر سێرڤەری لۆکاڵی وەک XAMPP یان Laragon دامەزراندبێت و بتوانیت فایلی `.php` لەناو براوسەردا بکەیتەوە (وانەی 1.4).

## ڕوونکردنەوە
لە زۆربەی زمانە بەرنامەسازییەکاندا، پێش بەکارهێنانی variable دەبێت جۆرەکەی دیاری بکەیت. PHP جیاوازە — پێی دەڵێن Loosely Typed، واتە تۆ تەنها ناوی variable دادەنێیت و بەهایەکی پێدەدەیت، PHP خۆی لە کاتی کارپێکردندا بەپێی بەهاکە جۆرەکەی دیاری دەکات.

هەر variable ـێک لە PHP هەمیشە بە نیشانەی دۆلار (`$`) دەستپێدەکات، دوای ئەوە ناوێک کە دەبێت بە پیت یان underscore (`_`) دەستپێبکات (نەک بە ژمارە). بۆ نموونە `$name` و `$age` و `$user_email` دروستن، بەڵام `$1name` هەڵەیەکی سینتاکسییە.

### چوار جۆری سەرەکی داتا (Data Types)
چوار جۆری سەرەتایی و گرنگ هەن کە دەبێت لەم قۆناغەدا بناسیت:
1. **string**: زنجیرە نووسین و دەق، کە لەناو کەوانەی تاکی `'...'` یان دووانەی `"..."` دادەنرێت (وەک `"ئارام"`).
2. **int** (یان Integer): ژمارەی تەواوی بێ پۆینت و کەرت، ئەرێنی یان نەرێنی (وەک `25` یان `-10`).
3. **float**: ژمارەی خاڵدار و کەرت (وەک `1.75` یان `99.9`).
4. **boolean**: تەنها یەکێک لەم دوو بەهایە وەردەگرێت: `true` یان `false` (بۆ مەرج و لۆژیک).

### ئۆپەرەیتەرەکان (Operators)
بۆ ئەنجامدانی کردار و بەراوردکاری لەسەر بەهاکان، ئۆپەرەیتەر بەکاردەهێنین:
- **Arithmetic (حیسابکاری):** کۆکردنەوە (`+`)، لێدەرکردن (`-`)، لێکدان (`*`)، دابەشکردن (`/`)، و مۆدیولۆ (`%`).
- **Comparison (بەراوردکردن):** 
  - یەکسانکردنی بەها (`==`): تەنها بەهاکان بەراورد دەکات بەبێ جۆر.
  - یەکسانکردنی بەها و جۆر (`===`): توندوتۆڵە، هەم بەها و هەم جۆری داتاکە دەبێت یەکسان بن. ئەمە گرنگترین جیاوازییە لە PHP کە پێویستە هەمیشە لەبەرچاوی بگریت!
  - جیاوازە (`!=` یان `!==`)، گەورەتر (`>`)، بچووکتر (`<`).
- **Logical (لۆژیکی):** AND (`&&`)، OR (`||`)، NOT (`!`).
- **Assignment (دانان):** دانانی بەها (`=`)، یان کورتکراوە وەک (`+=`, `-=`).

## نموونەی کۆد
فایلێک بە ناوی `lesson2_1.php` لەناو فۆڵدەری پڕۆژەکەت دروست بکە و ئەم کۆدە تاقی بکەرەوە:

```php
<?php
// 1. دروستکردنی variable بە جۆری جیاواز
$name = "ئارام";
$age = 25;
$height = 1.75;
$isStudent = true;

// 2. بەکارهێنانی Arithmetic Operator
$nextYearAge = $age + 1;

// 3. بەراوردکردنی دوو هاوکێشە (==) بەرامبەر سێ هاوکێشە (===)
echo "<pre>";
var_dump(5 == "5");   // دەردەچێت: bool(true)  — چونگە تەنها بەها بەراورد دەکات
var_dump(5 === "5");  // دەردەچێت: bool(false) — چونگە جۆرەکان جیاوازن (int بەرامبەر string)
echo "</pre>";

// 4. دەرخستنی دەرئەنجامەکان بە دەق
echo "ناو: $name, تەمەن: $age, باڵا: $height مەتر, ساڵی داهاتوو دەبیتە: $nextYearAge ساڵ.";
?>
```

## هەڵە باوەکان
1. **لەبیرکردنی نیشانەی دۆلار ($):** نووسینی `name = "ئارام"` لە جیاتی `$name = "ئارام"` دەبێتە هۆی `Parse error / Syntax error`.
2. **تێکەڵکردنی یەک هاوکێشە (=) لەگەڵ دوو هاوکێشە (==):** نووسینی `if ($age = 18)` لە جیاتی `if ($age == 18)`. یەکەمیان بەهای 18 دەخاتە ناو `$age` و هەمیشە وەک ڕاست (`true`) تەماشا دەکرێت، لە کاتێکدا مەبەستت پشکنینی تەمەن بووە.
3. **پشتگوێخستنی سێ هاوکێشە (===):** زۆر کەس وا دەزانن `==` و `===` وەک یەکن. نەخێر، بەکارهێنانی `==` دەتوانێت کێشەی ئەمنی و لۆژیکی دروست بکات چونکە string و int بە یەکسان دادەنێت.

## ئەزموون (Practice)
فایلێکی نوێی PHP دروست بکە بەم مەرجانەی خوارەوە:
1. دوو گۆڕاو (variable) دروست بکە: `$birthYear` (ساڵی لەدایکبوونت بە ژمارە) و `$currentYear` (ساڵی ئێستا، وەک 2026).
2. بە بەکارهێنانی ئۆپەرەیتەری کەمکردنەوە (`-`)، تەمەنی خۆت لەناو گۆڕاوی `$myAge` بژمێرە.
3. گۆڕاوێکی boolean دروست بکە بە ناوی `$isAdult` کە پشکنین بکات ئایا تەمەنت لە 18 گەورەتر یان یەکسانە (`$myAge >= 18`).
4. بە `echo` ڕستەیەک پیشان بدە کە تەمەنت ڕوون بکاتەوە.

**پێوەری سەرکەوتن:** فایلەکە لە وێبگەڕدا بێ هیچ هەڵەیەک تەمەنی دروست دەربخات و `var_dump($isAdult)` بەهای `true` پیشان بدات.

## وەڵامی پێشنیارکراو
```php
<?php
$birthYear = 2002;
$currentYear = 2026;

// ئەژمارکردنی تەمەن
$myAge = $currentYear - $birthYear;

// پشکنینی گەورەبوون
$isAdult = $myAge >= 18;

echo "تەمەنی ئێستام: $myAge ساڵە.<br>";

// نیشاندانی دۆخی boolean
echo "ئایا پێگەیشتووە (Adult)؟ ";
var_dump($isAdult);
?>
```

## کورتەی وانە
- لە PHP دا هەموو گۆڕاوێک بە نیشانەی دۆلار (`$`) دەستپێدەکات و پێویست ناکات جۆری داتاکەی پێشوەخت دیاری بکەیت.
- چوار جۆری سەرەتایی داتا بریتیین لە: `string`, `int`, `float`, `boolean`.
- ئۆپەرەیتەری `==` تەنها بەها بەراورد دەکات، بەڵام `===` هەردوو بەها و جۆری داتاکە بەراورد دەکات — هەمیشە پێشنیار دەکرێت `===` بەکاربهێنیت.
- ئاگاداربە لە نێوان دانانی بەها (`=`) و بەراوردکردن (`==`).
